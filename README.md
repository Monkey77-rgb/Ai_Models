# Ai_Models

A small local AI agent experiment (`agent.py`, `master_agent.py`), plus optional desktop dotfiles in `Hardware/dotfiles/`.

## Run
```sh
./launch_agent.sh      # opens agent.py in a kitty window
```
Paths resolve relative to the repo folder, so you can clone it anywhere. To use the dotfiles, see `Hardware/dotfiles/.config` and the Customized-Lubuntu README.
